Name_Lists is used for rapidly generating names and information for characters in fictional sports leagues or large scale roleplaying games.  The "player_creator" python script was written by Scott Wambold at Great Lakes Game Library as is available as open source under CC BY-SA 4.0 (attribute and share).  

Lists of resources come from several sources, including:
-Dungeon Crawl Classics Core Rules v11
-Mystery Science Theater 3000
-Deadball: Baseball With Dice
-MLB and NHL Histories
-Viewers like you
